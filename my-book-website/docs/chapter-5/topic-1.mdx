# Assessments

## ROS 2 Package Development Project
Develop a complete ROS 2 package that implements a specific robotic function, such as navigation, perception, or manipulation. Students will be evaluated on:
- Proper ROS 2 architecture implementation
- Correct use of nodes, topics, services, and actions
- Code quality and documentation
- Performance in simulated environment

## Gazebo Simulation Implementation
Create a robotic simulation scenario that includes:
- Accurate physical modeling
- Sensor integration and simulation
- Realistic environmental conditions
- Performance evaluation metrics

## Isaac-based Perception Pipeline
Design and implement a perception pipeline using NVIDIA Isaac tools that includes:
- Sensor data processing
- Computer vision algorithms
- Machine learning model integration
- Performance evaluation and optimization

## Evaluations
Each assessment evaluates the student's understanding of Physical AI principles and implementation skills. Projects are tested both in simulation and (when possible) on physical hardware.
