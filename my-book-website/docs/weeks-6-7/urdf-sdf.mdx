# URDF and SDF Robot Description Formats

## Unified Robot Description Format (URDF)

URDF (Unified Robot Description Format) is the XML-based format primarily used in ROS to describe robots. It defines the physical and visual properties of a robot, including its kinematic structure, inertial properties, visual meshes, and collision models.

### Basic URDF Structure

```xml
<?xml version="1.0"?>
<robot name="simple_robot" xmlns:xacro="http://ros.org/wiki/xacro">
  <!-- Base link -->
  <link name="base_link">
    <visual>
      <geometry>
        <cylinder length="0.6" radius="0.2"/>
      </geometry>
      <material name="blue">
        <color rgba="0 0 0.8 1"/>
      </material>
    </visual>
    <collision>
      <geometry>
        <cylinder length="0.6" radius="0.2"/>
      </geometry>
    </collision>
    <inertial>
      <mass value="10"/>
      <origin xyz="0 0 0"/>
      <inertia ixx="1.0" ixy="0.0" ixz="0.0" iyy="1.0" iyz="0.0" izz="1.0"/>
    </inertial>
  </link>

  <!-- Attached link via joint -->
  <link name="upper_plate">
    <visual>
      <geometry>
        <box size="0.5 0.5 0.01"/>
      </geometry>
      <origin xyz="0 0 0.31"/>
      <material name="red">
        <color rgba="0.8 0 0 1"/>
      </material>
    </visual>
  </link>

  <joint name="base_to_upper_plate" type="fixed">
    <parent link="base_link"/>
    <child link="upper_plate"/>
    <origin xyz="0 0 0"/>
  </joint>
</robot>
```

### Link Elements

Every rigid body in the robot is represented by a `<link>` tag with:

- `name`: Unique identifier for the link
- `<visual>`: How the link looks during visualization
- `<collision>`: How the link behaves during collision detection
- `<inertial>`: Physical properties for simulation

```xml
<link name="wheel_link">
  <visual>
    <origin xyz="0 0 0" rpy="0 0 0"/>
    <geometry>
      <mesh filename="package://my_robot_description/meshes/wheel.dae"/>
    </geometry>
    <material name="wheel_color">
      <color rgba="0.2 0.2 0.2 1.0"/>
    </material>
  </visual>
  <collision>
    <origin xyz="0 0 0" rpy="0 0 0"/>
    <geometry>
      <cylinder length="0.05" radius="0.1"/>
    </geometry>
  </collision>
  <inertial>
    <origin xyz="0 0 0" rpy="0 0 0"/>
    <mass value="1.0"/>
    <inertia ixx="0.01" ixy="0.0" ixz="0.0" iyy="0.01" iyz="0.0" izz="0.02"/>
  </inertial>
</link>
```

### Joint Elements

Joints connect links and define how they can move relative to each other:

- `type`: revolute, continuous, prismatic, fixed, floating, planar
- `name`: Unique identifier
- `parent`: Parent link name
- `child`: Child link name
- `axis`: Rotation or translation axis
- `limits`: Movement constraints for actuated joints

```xml
<joint name="wheel_joint" type="continuous">
  <parent link="base_link"/>
  <child link="wheel_link"/>
  <origin xyz="0.3 -0.2 0" rpy="0 0 0"/>
  <axis xyz="0 1 0"/>
  <limit effort="10" velocity="100"/>
</joint>
```

### Transmission Elements

Transmissions connect joints to actuators:

```xml
<transmission name="wheel_trans">
  <type>transmission_interface/SimpleTransmission</type>
  <joint name="wheel_joint">
    <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>
  </joint>
  <actuator name="wheel_motor">
    <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>
    <mechanicalReduction>1</mechanicalReduction>
  </actuator>
</transmission>
```

## SDF (Simulation Description Format)

SDF (Simulation Description Format) is Gazebo's native format that can represent more complex features than URDF, including:

- Advanced physics properties
- Multiple robots in one file
- World descriptions
- Nested models
- Plugins for simulation

### Basic SDF Structure

```xml
<?xml version="1.0" ?>
<sdf version="1.7">
  <model name="simple_box">
    <pose>0 0 0.5 0 0 0</pose>
    <link name="link">
      <inertial>
        <mass>1.0</mass>
        <inertia>
          <ixx>0.083</ixx>
          <ixy>0.0</ixy>
          <ixz>0.0</ixz>
          <iyy>0.083</iyy>
          <iyz>0.0</iyz>
          <izz>0.083</izz>
        </inertia>
      </inertial>
      <collision name="collision">
        <geometry>
          <box>
            <size>1 1 1</size>
          </box>
        </geometry>
      </collision>
      <visual name="visual">
        <geometry>
          <box>
            <size>1 1 1</size>
          </box>
        </geometry>
        <material>
          <ambient>0.3 0.3 0.3 1</ambient>
          <diffuse>0.7 0.7 0.7 1</diffuse>
          <specular>1 1 1 1</specular>
        </material>
      </visual>
    </link>
  </model>
</sdf>
```

### SDF vs URDF Comparison

| Feature | URDF | SDF |
|---------|------|-----|
| Origin | Origin tag for transforms | Pose tag for transforms |
| Meshes | Direct mesh references | URI references |
| Plugins | Via Gazebo tags | Native support |
| Materials | Separate material tags | Part of visual tag |
| Worlds | Requires separate format | Native support |
| Nested Models | Not supported | Supported |

## Gazebo-Specific Tags in URDF

URDF files can include Gazebo-specific tags for simulation purposes:

```xml
<link name="sensor_link">
  <visual>
    <geometry>
      <box size="0.1 0.1 0.1"/>
    </geometry>
  </visual>
  <collision>
    <geometry>
      <box size="0.1 0.1 0.1"/>
    </geometry>
  </collision>
  <inertial>
    <mass value="0.1"/>
    <inertia ixx="0.001" ixy="0" ixz="0" iyy="0.001" iyz="0" izz="0.001"/>
  </inertial>
</link>

<gazebo reference="sensor_link">
  <material>Gazebo/Blue</material>
</gazebo>

<gazebo>
  <plugin name="camera_plugin" filename="libgazebo_ros_camera.so">
    <alwaysOn>true</alwaysOn>
    <updateRate>30.0</updateRate>
    <cameraName>front_camera</cameraName>
    <imageTopicName>image_raw</imageTopicName>
    <cameraInfoTopicName>camera_info</cameraInfoTopicName>
    <frameName>sensor_link</frameName>
  </plugin>
</gazebo>
```

## Conversion Between Formats

### URDF to SDF

```bash
# Convert URDF to SDF
gz sdf -p my_robot.urdf > my_robot.sdf
```

### Working with Xacro

Xacro (XML Macros) preprocesses URDF files to generate more concise descriptions:

```xml
<?xml version="1.0"?>
<robot xmlns:xacro="http://ros.org/wiki/xacro" name="xacro_robot">
  <!-- Define properties -->
  <xacro:property name="M_PI" value="3.1415926535897931" />
  
  <!-- Define a macro -->
  <xacro:macro name="wheel" params="prefix parent *origin">
    <joint name="${prefix}_wheel_joint" type="continuous">
      <xacro:insert_block name="origin"/>
      <parent link="${parent}"/>
      <child link="${prefix}_wheel_link"/>
      <axis xyz="0 1 0"/>
    </joint>
    
    <link name="${prefix}_wheel_link">
      <visual>
        <geometry>
          <cylinder radius="0.1" length="0.05"/>
        </geometry>
      </visual>
      <collision>
        <geometry>
          <cylinder radius="0.1" length="0.05"/>
        </geometry>
      </collision>
      <inertial>
        <mass value="1"/>
        <inertia ixx="0.01" ixy="0" ixz="0" iyy="0.01" iyz="0" izz="0.02"/>
      </inertial>
    </link>
  </xacro:macro>

  <!-- Use the macro -->
  <xacro:wheel prefix="front_left" parent="base_link">
    <origin xyz="0.5 0.3 0" rpy="0 0 0"/>
  </xacro:wheel>
</robot>
```

Compile xacro to urdf:
```bash
xacro my_robot.xacro > my_robot.urdf
```

## Best Practices

### URDF Best Practices

- Use consistent naming conventions
- Provide accurate inertial properties
- Separate visual and collision geometry appropriately
- Use fixed joints to establish reference frames
- Validate urdf using check_urdf tool
- Keep models lightweight for real-time simulation

### SDF Best Practices

- Organize models into logical hierarchies
- Use appropriate physics parameters (friction, restitution)
- Include proper material definitions
- Add plugins only when necessary
- Test models in simulation before deployment

## Troubleshooting

### Common Issues

1. **Invalid URDF**: Use `check_urdf` to validate
2. **Missing Transmissions**: ROS control requires transmissions
3. **Inertia Issues**: Check inertia tensor validity
4. **Joint Limits**: Ensure limits match real robot capabilities

### Validation Tools

```bash
# Check URDF
check_urdf my_robot.urdf

# View URDF in RViz
ros2 run rviz2 rviz2 -d `ros2 pkg prefix --share my_robot_description`/rviz/urdf.rviz

# Verify SDF
gz sdf -k my_model.sdf
```

URDF and SDF are fundamental formats for robot simulation. Understanding both allows you to effectively represent robots in both ROS (URDF) and Gazebo simulation environments (SDF).
